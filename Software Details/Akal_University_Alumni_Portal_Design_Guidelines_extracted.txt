AKAL UNIVERSITY

ALUMNI PORTAL — UI/UX & DESIGN GUIDELINES

Modern • Attractive • Animated • Akal University Branded

Visual reference: Akal University Prospectus 2026–27

1. Design Objective

The Akal University Alumni Portal should look like a modern premium digital university platform. The Prospectus 2026–27 is the primary visual branding reference. The website should retain the recognizable Akal University yellow, blue and dark navy identity while using modern UI patterns, animations, gradients, rounded cards and interactive dashboard components.

4. Gradient System

Gradients are allowed and should be used intentionally.

Akal Blue → Deep Blue for hero sections and major dashboard headers.

Akal Yellow → Bright Yellow for CTA/highlight areas.

Blue → Light Blue for analytics cards and decorative backgrounds.

Navy → Deep Blue for dark dashboard/sidebar sections.

Blue + subtle yellow glow for premium hero/dashboard visuals.

9. Dashboard Animation Guidelines

Animation is explicitly allowed for this project.

Cards can animate upward/fade-in on dashboard load.

Statistics can count up from zero to the final value.

Charts can animate when entering the viewport.

Buttons can have smooth hover/press effects.

Sidebar items can have active-state transitions.

Profile cards can slightly lift on hover.

Hero elements can use staggered entrance animation.

Page transitions can use short fade/slide effects.

Notifications can use subtle slide-in effects.

Avoid animations that delay usability or make forms difficult to operate.

10. Rounded Cards & Components

Rounded cards are encouraged.

Use medium-to-large border radius for dashboard cards.

Use larger radius for hero CTA panels and profile cards.

Use consistent radius across buttons, inputs, cards and modals.

Use soft shadows and occasional gradient borders.

Avoid making every small element excessively rounded; hierarchy should remain clear.

18. Responsive Design

Desktop: full sidebar, multi-column dashboards and large charts.

Tablet: collapsible navigation and two-column content where appropriate.

Mobile: bottom/slide navigation, single-column cards and horizontally scrollable filters.

Tables should become cards or horizontally scrollable layouts on small screens.

Charts must remain readable on mobile.

19. Design Consistency Rules

Akal University logo must use the approved asset without distortion.

Yellow and blue should remain the recognizable visual identity throughout the portal.

Buttons, badges, cards and forms should follow a reusable component system.

Do not use unrelated visual themes on different modules.

Animation timing should remain consistent.

Dark and light sections can both be used, but branding must remain obvious.

Images should be high-quality and optimized for web performance.

21. Final Visual Target

The final product should feel like a combination of Akal University's official visual identity and a modern premium alumni networking platform. It should be visually rich, animated and engaging, while remaining professional enough for official university use.

Target: Akal University branding + premium modern dashboard + engaging animations + responsive UX.
